## 2. Offline Service Worker (`sw.js`)
Implement a lightweight Cache-First service worker:
- **Pre-cached Assets**: `index.html`, `engine.js`, `manifest.webmanifest`, CSS fonts/stylesheets, and icon assets.
- **Cache Invalidation**: Auto-bump cache version key on builds (`undoku-core-v1.x.x`).
- **Registration Pipeline**: Register the service worker in the main client HTML on `window.load` without blocking canvas initialization.

```javascript
const CACHE_NAME = 'undoku-core-v1';
const ASSETS_TO_CACHE = [
  './',
  './index.html',
  './engine.js',
  './manifest.webmanifest',
  './icons/icon.svg',
  './icons/icon-192.png',
  './icons/icon-512.png'
];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS_TO_CACHE))
  );
  self.skipWaiting();
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.map((k) => {
          if (k !== CACHE_NAME) return caches.delete(k);
        })
      )
    )
  );
  self.clients.claim();
});

self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((cachedResponse) => {
      return cachedResponse || fetch(event.request);
    })
  );
});
```

## Appendix: Upstream UI & Architecture Specifications

### A.1 Multi-Step New Game Dialogue Architecture
1. **Step 1: Size & Grid Topology Selection Modal (`#sizeSelectModal`)**
   - Direct entry from **🎲 NEW GAME** button.
   - Grid cards for all supported configurations: `4×4 Mini`, `6×6 Wide`, `8×8 Wide`, `9×9 Classic`, `10×10 Decimal`, `12×12 Duodecimal`, `12×12 Wide-Band`, and `16×16 Hexadoku`.
   - Selecting a size automatically advances to Step 2.
2. **Step 2: 2-Wide Difficulty Grid Modal (`#diffSelectModal`)**
   - Displays active grid size header with **⬅ Back** navigation to Step 1.
   - 2-column responsive grid for `Easy`, `Medium`, `Hard`, `Extreme`, and full-width `Impossible`.
   - Selecting a difficulty tier advances to Step 3.
3. **Step 3: Confirmation & Mode Selection Modal (`#confirmModal`)**
   - Clean summary header (`Topology: <Size> • Difficulty: <Difficulty>`).
   - Mode selection: `🛡️ Catch Mistakes` (Assisted) vs `📰 Like Paper` (Pure).
   - Toggles for Hints, Digit Counters, Radial Number Ring, and Highlighter.
   - Navigation: **⬅ Back** to Step 2, **Cancel**, and **▶ Start Game**.
   - Redundant grid size dropdown removed to preserve clear single-responsibility dialog flow.

### A.2 High-Performance 16×16 Hexadoku Bitmask Engine
- **32-Bit Bitmask Constraint Propagation**: Solution counting and generator validation accelerated via bitwise `ctz` / `clz32` lookups in `countSolutions` and `fillGrid`, achieving < 25ms generation times for 256-cell boards.
- **Triples Combinatoric Bounding**: Subset triple evaluations ($k=3$) bounded to $N \le 9$ or $\le 8$ open unit cells to prevent combinatorial explosions on large matrices.
- **Forced Branch Lookahead Fallback**: Guarantees 100% deductive completion for any valid puzzle across all dimensions without unresolved blanks.
