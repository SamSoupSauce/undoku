# Engine & UI Extension: Generalized Rectangular Subgrid Topology ($B_r \times B_c$) & Dynamic Board Scaling

## Overview & Objective
Generalize Undoku from a fixed $9 \times 9$ ($3 \times 3$ box) board to an arbitrary $N \times N$ matrix parameterized by rectangular subgrid dimensions $(B_r, B_c)$ where $N = B_r \times B_c$. This unlocks support for standard square grids ($4 \times 4, 9 \times 9, 16 \times 16$) as well as non-square subgrid configurations ($6 \times 6$ with $2 \times 3$, $8 \times 8$ with $2 \times 4$, and $12 \times 12$ with $3 \times 4$ or $2 \times 6$).

---

## 1. Mathematical Architecture & Indexing Invariants

Let $B_r$ be the subgrid box row count (height in cells) and $B_c$ be the subgrid box column count (width in cells).

* **Total Grid Dimension**: $N = B_r \times B_c$
* **Total Distinct Symbols**: $N$
* **Total Subgrid Boxes on Board**: $N$ (arranged as $B_c$ horizontal bands of boxes and $B_r$ vertical stacks of boxes)
* **Cell to Box Indexing**:
  $$\text{BoxIndex}(r, c) = \left\lfloor \frac{r}{B_r} \right\rfloor \times B_r + \left\lfloor \frac{c}{B_c} \right\rfloor$$
* **Box Origin Bounds**:
  $$\text{BoxStartRow}(\text{boxId}) = \left\lfloor \frac{\text{boxId}}{B_r} \right\rfloor \times B_r$$
  $$\text{BoxStartCol}(\text{boxId}) = (\text{boxId} \bmod B_r) \times B_c$$

function drawDynamicGrid(ctx: CanvasRenderingContext2D, width: number, height: number, Br: number, Bc: number) {
  const N = Br * Bc;
  const cellW = width / N;
  const cellH = height / N;

  // 1. Thin internal cell borders
  ctx.strokeStyle = "var(--grid-line)";
  ctx.lineWidth = 1;
  for (let i = 1; i < N; i++) {
    if (i % Bc !== 0) {
      ctx.beginPath();
      ctx.moveTo(i * cellW, 0);
      ctx.lineTo(i * cellW, height);
      ctx.stroke();
    }
    if (i % Br !== 0) {
      ctx.beginPath();
      ctx.moveTo(0, i * cellH);
      ctx.lineTo(width, i * cellH);
      ctx.stroke();
    }
  }

  // 2. Thick subgrid box borders
  ctx.strokeStyle = "var(--box-line)";
  ctx.lineWidth = 2.5;
  for (let c = 0; c <= N; c += Bc) {
    ctx.beginPath();
    ctx.moveTo(c * cellW, 0);
    ctx.lineTo(c * cellW, height);
    ctx.stroke();
  }
  for (let r = 0; r <= N; r += Br) {
    ctx.beginPath();
    ctx.moveTo(0, r * cellH);
    ctx.lineTo(width, r * cellH);
    ctx.stroke();
  }
}
