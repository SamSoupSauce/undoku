Feature Specification: Home Dashboard, Navigation Router & Saved Puzzle Hub

Overview & Objective

Replace the default "auto-load random puzzle on boot" behavior with a structured Home Dashboard & Navigation Hub. Players landing on Undoku will be greeted with a polished central hub where they can resume in-progress games, review past puzzle analytics and polar graphs, browse their local IndexedDB library, or kick off a fresh puzzle with custom grid dimensions and difficulty parameters.

1. Application Screen State Machine (router.ts)

Introduce a lightweight, client-side screen state machine to manage view rendering and navigation history without full page reloads.

export type ScreenState = 
  | 'HOME_MENU'        // Central Hub / Dashboard
  | 'GAME_PLAY'        // Active Canvas Puzzle Screen
  | 'REPLAY_VIEWER'    // Step-by-Step Replay & Analytical Breakdown
  | 'THEME_STUDIO'     // Visual Palette & UI Geometry Editor
  | 'SETTINGS_PRIVACY' // Local Storage Management & Data Export

export interface NavigationState {
  currentScreen: ScreenState;
  activeGameId: string | null;
  previousScreen: ScreenState | null;
}


View Transition Rules

Boot Behavior: Default to HOME_MENU. If an active, uncompleted puzzle exists in localStorage/IndexedDB, display a prominent "Resume In-Progress Game" card on the dashboard.

Non-Destructive Navigation: Opening the Menu, Theme Studio, or Analytics Viewer while playing pauses the timer and preserves the active canvas state. Returning to GAME_PLAY resumes seamlessly.

2. Dashboard Interface Components (MenuHubView)

A. Quick Action & Launcher Bar

"New Game" Button: Opens the 2-step setup modal (Board Geometry $B_r \times B_c$ + Difficulty Tier $1..8$).

"Resume Game" Card: Displays thumbnail grid preview, current completion percentage, elapsed time, and difficulty badge.

B. "My Puzzle Library" Shelf (IndexedDB Vault)

An interactive gallery of local puzzle records categorized into three tabs:

In-Progress: Saved drafts auto-updated on every move.

Completed Vault: Solved puzzles showing total time, mistake count, and mini polar spike graph thumbnails.

Imported & Shared: Puzzles received via 6-character shortcode or offline QR code.

C. Replay & Analytical Deep-Dive Entry Points

Tapping any completed record opens REPLAY_VIEWER to review step-by-step logic deductions, assertion curves, and export SVG replay animations.

Library Vault: Operates asynchronously against IndexedDB (undoku_db_v1), fetching indexed summaries (id, timestamp, difficulty, progressPct, polarGraphData) without loading full turn histories into memory until requested.

4. First-Run & Empty State Experience

When no local puzzle records exist:

Render a minimalist onboarding card highlighting Undoku's core principles: Deterministic Solving, Zero Tracking, and Granular Cognitive Analytics.

Provide a "Quick Start (Classic 9x9 Medium)" single-click button for immediate entry.

Acceptance Criteria

[ ] Launching Undoku opens the Home Dashboard instead of immediately dropping the user onto an unconfigured game board.

[ ] Active in-progress games display a "Resume" banner with accurate progress percentage and elapsed time.

[ ] Users can navigate between Dashboard, Active Game, Replay Viewer, and Theme Studio without losing active board state or timer state.

[ ] Saved games and replays in IndexedDB render as selectable cards with thumbnail previews.

[ ] Quitting or completing a game cleanly returns the player to the Home Dashboard with updated stats.
