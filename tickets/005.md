Task: Refactor Sudoku mobile touch interactions and implement orbiting radial input ring.

Objectives:
1. Implement Deterministic Two-Tap State Machine:
   - Replace any double-tap listeners or delay-based touch logic with a deterministic state controller:
     * Tap 1 (unfocused cell or different cell): Set focus to that cell. Keep ring closed.
     * Tap 2 (tap on the currently active/focused cell): Open the radial digit selector centered on the active cell.
     * Tap outside (or backdrop): Dismiss ring, clear focus, return to IDLE.

2. Dynamic Radial Ring Mechanics:
   - Exclude exhausted digits (digits where all 9 instances are placed on the board).
   - Equidistantly space the remaining available digits in a circular layout around the cell center.
   - Include a centered cancel button labeled 'X' in the middle of the radial ring.
   - Implement continuous slow-orbit rotation (~0.005 rad/frame) driven via requestAnimationFrame.
   - Apply counter-rotation to individual digit elements so numbers remain vertically upright as the parent ring rotates.

3. Performance & Cleanup:
   - Ensure cancelAnimationFrame is called whenever the ring is dismissed or a digit is committed.
   - Prevent mobile scroll/zoom interference on touch targets (touch-action: none on ring elements).
   - Write/update unit tests to verify the two-tap state transitions and digit filter logic.
